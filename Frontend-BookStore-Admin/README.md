# BookStore Admin (Web)

Giao diện quản lý sản phẩm, đơn hàng và giỏ hàng cho BookStore API.

## Chạy

1. Backend: `D:\Duan1\Backend-BookStore` — `npm start` (cổng 3000)
2. Seed admin (lần đầu): `npm run seed` — `admin@bookstore.vn` / `123456`
3. Frontend:

```bash
cd D:\Duan1\Frontend-BookStore-Admin
npm run dev
```

Mở URL Vite in ra (thường **http://localhost:5173**).

## Cấu hình

`.env`: `VITE_API_URL=http://localhost:3000`
